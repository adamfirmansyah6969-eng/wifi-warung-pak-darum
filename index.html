Stok Voucher

Import CSV (format MikroTik)

Format CSV MikroTik: Username, Password, Profile, Time Limit, Data Limit, Comment (contoh: ABC1234, ABC1234, voucher-6-jam-2000, 6h). Kolom Username dibaca sebagai kode voucher, Profile + Time Limit dipakai untuk menebak paket otomatis (tampil di bawah — periksa, kalau salah ganti manual). Kolom Password diabaikan sepenuhnya — tidak disimpan, tidak ditampilkan, tidak dicetak.

Pilih file CSV — paket akan terdeteksi otomatis dari Profile. Contoh format: Username,Password,Profile,Time Limit,Data Limit,Comment.

🖨️ Cetak Massal Voucher

Cetak banyak struk voucher sekaligus (satu halaman 58mm per voucher, lengkap dengan QR + kode besar) untuk stok di warung. Voucher yang dicetak belum terjual — saat pelanggan membayar, kasir isi kode dari struk itu di kolom "Kode voucher tertentu" di menu Kasir.

✨ Buat Voucher Otomatis

Buat kode voucher baru langsung dari aplikasi (huruf/angka tanpa 0, O, 1, I, L agar tidak salah baca). PENTING: kode ini belum ada di MikroTik — setelah dibuat, ekspor CSV di bawah lalu import ke MikroTik/User Manager, baru bisa dipakai pelanggan.

⬇ Ekspor CSV untuk MikroTik

Ekspor stok tersedia dalam format CSV MikroTik (Username,Password,Profile,Time Limit,Data Limit,Comment) untuk diimport ke router. File ini berisi password (= kode voucher) — hanya untuk admin.

Pengaturan

🏪 Nama warung & WiFi

Alamat halaman login hotspot MikroTik. QR di struk akan membuka alamat ini dengan username & password terisi — bila halaman login warung mendukung isi otomatis dari URL. Bila dikosongkan, QR hanya berisi kode voucher. Ganti 192.168.88.1 dengan IP hotspot warung.

💰 Harga paket (Rp)

🎟️ Kode Promo

Kode promo dipotong dari harga paket di Kasir. Contoh yang sudah aktif: HEMAT500 (potongan Rp500, semua paket).

📱 Gambar QRIS statis

Upload gambar QRIS dari merchant. Gambar disimpan di perangkat ini saja.

🔒 PIN kasir

PIN default: 1234. Segera ganti. PIN ini hanya kunci layar di browser — bukan keamanan server dan tidak melindungi data dari orang yang membuka file/database perangkat ini.

💾 Backup & Restore

Backup berisi semua transaksi, stok, dan tutup kas. Simpan file backup di tempat aman. Data hanya tersimpan di perangkat ini — tidak tersinkronisasi antarperangkat.

⚠️ Reset data

Menghapus semua transaksi, stok, dan tutup kas di perangkat ini. Tidak bisa dibatalkan.
